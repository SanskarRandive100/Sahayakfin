# SahayakFin

Alternative credit scoring and financial wellness for gig workers (hackathon prototype). All data is synthetic.

- Product: `docs/PRODUCT.md` · Contracts: `docs/CONTRACTS.md` · Team plan: `docs/TEAM_PLAN.md`
- Run the backend: `cd backend && pip install -r requirements.txt && uvicorn app.main:app --reload --port 8000`
- Run the frontend: `cd frontend && npm install && npm run dev`
- Generate the sample data: `python data/generate_personas.py`
